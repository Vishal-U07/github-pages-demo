Overview

Electrocardiography (ECG) is a non‑invasive technique that records the heart's electrical activity and helps detect abnormalities such as arrhythmias, ischemia, and myocardial infarction.

This project focuses on deep learning‑based ECG retrieval (not only classification) to compare a patient's ECG with historical cases, enabling scalable and reliable clinical decision support.

Literature review highlights

Existing work

  • Foundation Models for ECG (2025): Large FM with embeddings, but no retrieval stack or ANN indexing.
  • HeartBERT (2024): Transformer pretraining, no scalable similarity search.
  • PCLR (2022): Patient contrastive learning, no full retrieval pipeline.
  • CLOCS (2021): Self-supervised pretraining, no end-to-end retrieval system.

Our gap-filling

  • ECG-to-ECG retrieval (not just classification).
  • FAISS for scalable similarity search.
  • Deployable workflow for clinical use.
  • Contrastive learning + embeddings for richer representations.

Aim & objectives

Aim: Design a deep learning‑based ECG retrieval system that enables scalable and accurate clinical decision support by retrieving patient records with similar cardiac patterns.

  • Preprocess and use benchmark datasets (e.g., PTB‑XL) to ensure high‑quality input for training and evaluation.
  • Implement deep neural networks (e.g., Siamese/embedding models) to learn robust ECG feature representations.
  • Use pairwise learning + contrastive loss to separate similar vs dissimilar ECG signals in embedding space.
  • Use FAISS (Facebook AI Similarity Search) for efficient large‑scale similarity retrieval.
  • Evaluate using retrieval metrics: Top‑k accuracy, precision, recall; benchmark vs classification baselines.
  • Ensure scalability/adaptability for real deployment in hospital/clinical databases.

Methodology

Datasets

  • PTB‑XL: large‑scale clinical ECG dataset (primary).
  • MIT‑BIH Arrhythmia Database: benchmark dataset for testing.

Software & libraries

  • Python
  • PyTorch / TensorFlow (deep learning)
  • FAISS (similarity search + indexing)

Retrieval pipeline

  1. Ingest ECG signals and preprocess into a consistent format.
  2. Train an embedding model (Siamese style) using contrastive/pairwise learning.
  3. Store embeddings in a FAISS index for fast Approximate Nearest Neighbor search.
  4. For a query ECG, compute its embedding and retrieve Top‑K similar cases.

Evaluation

Evaluate retrieval performance using Top‑k accuracy, precision, and recall, and compare against classification baselines.

Deployment plan

Real-time ECG retrieval supports faster, evidence-based clinical decisions. Deployment ensures repeatability, accessibility, and transparency in real workflows.

Prototype UI

  • Streamlit / Gradio for rapid demos and clinician trials.

Backend & infrastructure

  • FastAPI backend + FAISS index for low-latency retrieval.
  • Docker containerization for portability.
  • Azure/AWS hosting for scalability; future EHR integration.
