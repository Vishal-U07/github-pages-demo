Introduction

Electrocardiography (ECG) is a non-invasive technique that records the heart’s electrical activity to detect abnormalities such as arrhythmias, ischemia, and myocardial infarction, and is widely used in hospitals and clinics.

This project focuses on deep learning-based ECG retrieval rather than simple classification: a query ECG is compared with historical cases to support scalable and reliable clinical decision support and improve diagnostic efficiency and accuracy.

Aim & objectives

Aim: To design and develop an ECG retrieval system using deep learning for clinical decision support.

  • Preprocess and utilize benchmark ECG datasets (e.g., PTB‑XL) for reliable model training and evaluation.
  • Develop deep metric learning models (Triplet Loss) for robust ECG feature representations.
  • Implement similarity learning to distinguish similar vs dissimilar ECG signals.
  • Enable fast large-scale ECG retrieval using FAISS indexing.
  • Evaluate using retrieval metrics such as Top‑K accuracy, precision, and recall.
  • Design a scalable framework suitable for real-world clinical and hospital database deployment.

Workflow: ECG retrieval pipeline

Block A — Data input & preprocessing

Raw 12‑lead ECG signals are loaded from PTB‑XL, cleaned to reduce noise/inconsistencies, standardized using Z‑score normalization, and lightly augmented (scaling, small time shifts) to improve robustness.

Block B — Segmentation & feature learning

Signals are divided into fixed 10‑second overlapping sliding windows. A 1D CNN embedding network extracts waveform features and converts each segment into a compact 128‑dimensional embedding vector.

Block C — Similarity search & metric learning

Triplet loss learns meaningful similarity: embeddings of similar ECGs are pulled closer while dissimilar ECGs are pushed apart. FAISS enables fast large-scale nearest-neighbour similarity search to retrieve the most similar ECG signals from the database.

Block D — Diagnosis aggregation & output

Top‑K similar ECGs are collected, and their diagnosis labels are analyzed to identify dominant patterns. The system outputs similar past ECG cases rather than a direct diagnosis to support clinical decision making.

Model architecture (ECGEmbeddingNet)

Core design

  • Model type: CNN-based ECG embedding network
  • Input: 12‑lead ECG signal
  • Input size: (12 × 1000) (10 seconds @ 100 Hz)
  • Feature extractor: Convolutional layers (temporal features) + temporal pooling
  • Activation: ELU / ReLU
  • Normalization: Batch normalization

Embedding & similarity

  • Embedding layer: Fully connected
  • Embedding dimension: 128
  • Embedding normalization: L2 normalization (unit vector)
  • Similarity: Euclidean / cosine distance
  • Objective: Triplet margin loss (margin = 1.0)
  • Task: ECG similarity retrieval
